## 📝 Description

**Antishoot** is a commercial PC game built from the ground up to deliver a distinct and engaging experience. Developed entirely in **Unity** using **C#**, the project heavily leverages the **Universal Render Pipeline (URP)** to achieve a striking low-fidelity retro visual style. By utilizing custom dithering shaders, toon shading, and a carefully crafted pixelated aesthetic, *Antishoot* blends nostalgic visual design with modern engine capabilities and smooth performance.

## ✨ Key Features & Visuals

- **Custom Low-Fi Aesthetics:** Distinctive retro look achieved through specialized hand-coded dithering and toon shaders.
- **URP Optimization:** Fully integrated with Unity's Universal Render Pipeline to balance a highly stylized pixelated look with optimal PC performance.
- **Robust Architecture:** Core mechanics, game logic, and interactions built with clean, maintainable C# scripting.
- **Custom Asset Pipeline:** 3D models and 2D graphic elements meticulously crafted from scratch to fit the game's unique atmosphere.

## 🛠️ Tech Stack & Tools

- **Game Engine:** Unity (URP)
- **Programming Language:** C#
- **3D Modeling & Assets:** Blender
- **Graphic Design & UI:** Adobe Photoshop, Adobe Illustrator
- **Version Control:** Git / GitHub
